# EduStar

Page d'accueil des révisions de collège : elle regroupe les cours et les jeux de révision.

Je fais ces outils pour aider mon fils, en 5e, à apprendre et à réviser. C'est loin d'être complet : juste quelques outils pour l'aider, pas un programme de cours.

- [Prépa dictée du brevet](https://tekio.org/prepa-dictee-brevet/) : cours pour préparer la dictée du brevet.
- [OrthoStar](https://tekio.org/orthostar/) : jeu d'orthographe (lexique, grammaire, conjugaison).
- [HistoStar](https://tekio.org/histostar/) : QCM d'histoire par chapitre.
- [SVTStar](https://tekio.org/svtstar/) : QCM de SVT par chapitre.

En ligne : https://tekio.org/edustar/

Les liens vers les projets sont relatifs (`../orthostar/`…) : ils fonctionnent en ligne, où tous les sites sont voisins sur tekio.org, et en local quand les dépôts sont côte à côte. Chaque projet renvoie vers EduStar depuis sa barre du haut.
